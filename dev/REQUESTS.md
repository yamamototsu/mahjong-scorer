# 依頼箱（やってほしいことリスト）

**使い方: 下の「未対応」に箇条書きで足すだけ。いつでも、いくつでも。順番も体裁も気にしなくて大丈夫です。**

- 書き足したら、そのまま閉じてOK。監督が定期的に見に来て、担当エージェントに割り振ります。
- 書き方は自由（例:「卓上の点数が見づらい」「東風戦のとき○○になる」「チップ機能がほしい」）。
- 「どの画面か」だけ分かると精度が上がります（分からなければ無しでOK）。
- 急ぎのものは行頭に `!` を付けてください。
- チャットで言ってもらってもOK。監督がここに転記します。
